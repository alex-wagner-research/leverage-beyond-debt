# Changelog

One entry per version of the data, newest first. The rules and rulings the data follow are in
`codebook.md`; a change to a value cites the filing it rests on.

## v1.1

With the paper's revised version of October 2026. No value, row or id changes. The codebook is now
written for the five tables this release holds: it defines every rule and ruling the tables cite,
and leaves out the tables, code and stress-test rulings the release does not include. The notes of
eighteen rows no longer record how a cell was edited or refer to a figure of an earlier draft.
Figure 2 is redrawn in the paper's current layout, with the same numbers.

## v1.0

The first public version, with the paper as first posted: the contract database for the 37
listed firms and their 155 arrangements, in five tables (the parties, the arrangements, their
legs, the firms' balance-sheet figures, and the quoted passages), and the paper's Figure 2 with
the numbers it plots. Later entries record every accepted correction with its issue number and
its filing basis.
